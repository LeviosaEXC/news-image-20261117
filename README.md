A single-page newspaper image summing up Tuesday 17 November 2026, drawn end to end as one broadsheet: a bold masthead and dateline up top, the Kerch Bridge as the lead story, a two-by-two grid of the day's other big stories, a by-the-numbers strip, and a news ticker along the foot. Every number on the page carries a caption, and every headline is drawn as part of the artwork.

## Entry files

- `entry.png` — the submitted image, a 1024 by 1024 JPEG
- `main.ts` — the entrypoint that serves the image

All artwork on the page is drawn, not pasted: masthead, headlines, figures, and ticker are part of the single image.
